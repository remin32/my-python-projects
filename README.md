# Telegram Bot Notes

Бот для хранения личных заметок в Telegram.

## Возможности

- Добавление заметок
- Просмотр всех заметок
- Удаление по номеру
- Отдельные заметки для каждого пользователя
- Данные хранятся в SQLite

## Технологии

- Python 3.13
- aiogram 3
- SQLite
- FSM (машина состояний)

## Установка

1. Клонируй репозиторий
2. Установи зависимости: `python -m pip install aiogram`
3. Создай `config.py` с токеном и прокси
4. Запусти: `python bot.py`
